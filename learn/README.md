# 从零建立 PX4 的系统理解

你要达到的是：看到一个飞行现象，知道它经过哪些模块；能从消息找到源码，从源码解释行为；能修改一个功能，并用测试、仿真和日志证明修改有效。学习对象固定为本仓库的 **PX4 v1.17.0**，先贯通四旋翼，再扩展到通信、其他机型和真实硬件。

## 只有三篇正文，按这个顺序使用

| **[二、系统学习路线](02-learning-path.md)** | 从阶段 1 开始，一次学习一个阶段。每阶段说明要解决的问题、阅读顺序、动手任务和应形成的能力。 |

## 你现在从哪里开始

你已经完成过编译和 SIH 四旋翼起降。先读 [PX4 是什么](01-understand-px4.md#c1)，接着读到 [消息、运行与启动](01-understand-px4.md#c4)。读完应该能回答：“没有 Gazebo 窗口，为什么飞机仍然能在仿真中起飞？”

然后进入 [阶段 1](02-learning-path.md#s1)，确认现有工程关系；接着做 [阶段 2 的起降观察](03-practice-guide.md#s2)。这次重点是解释目标、估计、控制与模式的变化。暂时不需要安装 ROS、重建镜像或购买硬件。

## 文档的适用范围

命令按你的 WSL、Docker、embedded-lab 环境编写，宿主源码路径为 `/home/yiyi/Workspace/px4/PX4-Autopilot`，容器路径为 `/workspaces/PX4-Autopilot`。正文中的源码链接直接指向本仓库，函数名和消息以 v1.17.0 为准。

基础构建、SIH 起降有你此前的运行记录；新实验按源码设计，需由你实际执行。本次文档编写核对了源码、命令形式和引用，没有运行 Docker、仿真或硬件实验。Gazebo、ROS 和真机阶段有各自的前置条件，不能用“读过”代替“完成过”。

旧教材已从工作树移除，历史版本可以在 Git 中查阅。今后就从本页进入，不需要安装学习工具、生成文档包或维护进度表。
